# Trang trí giấy note (`assets/paper/deco/`)

SVG vẽ tay bằng code cho giấy note của Mochi Notes. **Vẽ nguyên bản cho Mochi Notes, không dựa trên nhân vật có bản quyền; giấy phép theo dự án.**

## Quy ước
- Nét viền `#2b2420`, dày khoảng 2.5 (chi tiết nhỏ 1.5–2, hình lớn 3), đầu nét và góc nối tròn.
- Tô màu phẳng, pastel hoặc tươi vừa phải, có vệt sáng nhỏ; hơi không đều cho giống vẽ tay.
- `viewBox="0 0 64 64"` (trừ ghi chú khác), không `width`/`height` cố định, không script, ảnh ngoài, phông hay chữ.
- Rõ khi hiển thị nhỏ 28–56px.
